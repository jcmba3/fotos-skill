# Logos para la cabecera de las presentaciones

La skill de presentaciones de MBA3 ofrece como logo de cabecera los archivos `.svg` de esta carpeta.

- **Versión blanca o clara.** El logo va sobre la banda azul oscuro (Tinta, #123347) de las diapositivas.
- **Un `.png` con el mismo nombre al lado de cada `.svg`**, por ejemplo `smart-pos.svg` y `smart-pos.png`. PowerPoint 2016 o posterior muestra el SVG; las versiones anteriores y algunos visores solo muestran el PNG.
- **El nombre del archivo es el nombre que se ve en el formulario.** Los guiones y los guiones bajos se muestran como espacios.
- **Solo cuentan los archivos de la raíz** de esta carpeta. Cada SVG debe pesar menos de 300 KB y no puede llevar scripts.
